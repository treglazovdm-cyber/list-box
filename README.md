# LUMO — световые панели

Одностраничный каталог семи позиций световых панелей и напольных стоек.

Откройте `dist/index.html` в браузере для локального просмотра.

## Подключение формы заказа на сервере

На сервере с Ubuntu, где репозиторий находится в `/opt/list-box`, выполните от `root`:

```sh
cd /opt/list-box
git pull --ff-only origin main
bash deploy/setup-order-intake.sh
```

Скрипт обновляет файлы сайта, устанавливает CRM из репозитория `light-box-CRM-new` как службу `light-box-crm`, добавляет в Nginx только публичный endpoint `/api/site-order` и проверяет его тестовым запросом без создания записи.
